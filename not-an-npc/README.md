## 呢本手冊係乜

大部分人對危機嘅態度係「天跌落嚟當被冚」：平時唔諗，一旦發生，就好似遊戲入面嘅 NPC 咁企喺度，等人話佢知下一步做乜。

呢本手冊用淺白嘅方式，講四種而家多人擔心嘅危機：真實風險有幾大、平時可以點準備、真係發生咗應該點做。目的唔係製造恐慌，而係令你有準備，少啲擔心。

## 點用

每頁都分四部分，按次序睇：

1. **現實係點**：分清楚真實風險同被放大咗嘅恐懼
2. **常見誤解**：出事時會令人做錯決定嘅講法
3. **平時準備**：分「今日、今個月、長遠」，可以逐項剔
4. **如果發生喺你身上**：一步一步嘅行動，出事時打開照做

每頁最後有**日本**同**香港**嘅本地資源（存款保障、求助電話、失業支援等）。右上角可以切換**粵語（繁體）／English／日本語**。
